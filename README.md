# Explaze Family — портал RP-сообщества

Готовый full-stack сайт: регистрация и вход по никнейму/паролю, личный баланс, магазин, заявки на RP-мероприятия, автоматическое начисление награды после одобрения администратором, история операций и административная панель.

## Что реализовано

- Тёмный премиальный дизайн в духе RP-порталов.
- Регистрация и вход, пароли хранятся в виде bcrypt-хеша.
- Сессии хранятся в SQLite; cookie `HttpOnly` и `SameSite=Lax`.
- Магазин с категориями, покупка за материалы и проверка баланса на сервере.
- Подача заявок на 6 событий с заданными выплатами:
  - Успешная поставка — 500 матов.
  - Перехваченная поставка — 700 матов.
  - Отбитие ТЦ — 600 матов.
  - Успешный захват ТЦ — 800 матов.
  - Успешное похищение губернатора — 1 000 матов.
  - Отбитие губернатора — 900 матов.
- Одобрение/отклонение заявок администратором.
- Ручное начисление и списание материалов с обязательной причиной.
- История начислений и покупок.

## Запуск на Windows

1. Установи Node.js 18 или новее: https://nodejs.org/
2. Распакуй архив.
3. В папке проекта скопируй `.env.example` в `.env`.
4. В `.env` задай собственный длинный `SESSION_SECRET` и сложный `ADMIN_PASSWORD`. Не оставляй пароль-пример.
5. Открой терминал в папке проекта и выполни:

   ```bash
   npm install
   npm start
   ```

6. Открой http://localhost:3000
7. Войди с `ADMIN_USERNAME` и `ADMIN_PASSWORD` из `.env`. Администратор создаётся при первом старте.

## Важно перед публикацией в интернете

- Обязательно задай уникальный `SESSION_SECRET` и сильный `ADMIN_PASSWORD`.
- Размещай сайт только за HTTPS reverse proxy и установи `NODE_ENV=production`.
- Используй постоянный диск для папки `data/` — там база пользователей, балансы, заявки и сессии.
- Делай регулярные резервные копии `data/explaze.sqlite`.
- Регистрация открытая: любой посетитель может создать обычный аккаунт. Администратор создаётся только из переменных окружения при первом запуске.
- Сейчас награда за событие поступает на личный баланс аккаунта, который отправил заявку. Администратор проверяет материалы и доказательства перед начислением.
- Покупка фиксируется в истории и списывает маты; фактическую выдачу игрового предмета администратор выполняет в самой RP-игре.
- Это стартовый проект для сообщества, а не готовая публичная платформа с аудитом/модерацией. Перед большим запуском стоит добавить CAPTCHA, подтверждение аккаунта и резервное копирование по расписанию.

## Структура

- `server.js` — API, авторизация, база SQLite, магазин и админские действия.
- `public/index.html` — страницы портала.
- `public/styles.css` — дизайн.
- `public/app.js` — интерфейс и взаимодействие.
- `data/` — создаётся автоматически при первом запуске.
